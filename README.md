🕹️ Pixel Runner
Pixel Runner is a side-scrolling runner game built using Pygame.
The player controls a character that can jump to avoid incoming obstacles like snails and flies.
The game ends when the player collides with an obstacle.

🎮 Gameplay
Press SPACE to start the game.

Press SPACE again to jump when you're on the ground.

Avoid incoming obstacles.

The game ends on collision.

Your score is based on how long you survive.

🔧 Requirements
Python 3.7+

Pygame

Install Requirements
pip install pygame
